# Francisco Venes — Web Developer Portfolio

Personal portfolio showcasing my frontend development skills and selected projects, built to present my work to potential employers.

**Live website:** [francisco-venes.netlify.app](https://francisco-venes.netlify.app)

## Technologies

- HTML
- CSS
- JavaScript
- React
- Git
- Vite

## Features

- Responsive web design
- Project gallery
- Contact form

## Getting Started

Clone the repository, install dependencies, and start the development server:

```bash
git clone https://github.com/franciscovenes/portfolio.git
cd portfolio
npm install
npm run dev
```

Replace the placeholders with your repository URL and directory name.
